# Plan: Board Analysis Pipeline with OpenAI

## Context

MiroEx сериализует Miro-доски в текст, но шаг LLM-анализа ручной. В `_export.ts:39` прямо написано: "Files 03-analysis.md and 04-insights.md should be generated by LLM". Сейчас эти файлы создаются вручную через Claude Code. Нужно автоматизировать: сериализация → OpenAI API → `03-analysis.md` + `04-insights.md` → интерактивный чат.

Примеры ожидаемого output есть в `output/онтология/` и `output/Штуковина/`.

## Формат output (из существующих примеров)

### 03-analysis.md — структурный анализ доски
- Заголовок с board ID, датой, автором
- **Что это** — 2-3 предложения о назначении доски
- **Структура доски** — по каждому фрейму: содержимое, ключевые сущности и связи
- **Граф связей** — типы отношений, паттерны, мосты между фреймами
- **Цветовая кодировка** (если есть)
- **Статистика**

### 04-insights.md — инсайты и рекомендации
- **TL;DR** — 2-3 предложения суммаризация
- **Ключевые инсайты** — 3-5 пронумерованных наблюдений с пояснениями
- **Сильные стороны**
- **Слабые стороны / что доработать**
- **Рекомендации** — конкретные шаги
- **Статистика**

### 3. Update `src/cli.ts`

Добавить action `"analyze"` в `selectAction()`:
```
{ name: "Analyze (LLM summary + insights + chat)", value: "analyze" }
```

В `runAction()` case `"analyze"`:
1. `serializeBoard(cache)` → text
2. `analyzeBoard(text, ...)` → `{ analysis, insights }`
3. Печать analysis и insights в консоль
4. Сохранение в `output/<boardName>/03-analysis.md` и `04-insights.md`
5. Prompt: "Start interactive chat about the board?"
6. Если да → `chatAboutBoard(text, analysis, insights)`

### 4. Update `src/_export.ts`

Заменить комментарий на строке 39 на реальный вызов:
- После сохранения `01-raw-data.json` и `02-serialized.txt`
- Спросить: "Generate LLM analysis? (requires OPENAI_API_KEY)"
- Если да → `analyzeBoard()` → сохранить `03-analysis.md` и `04-insights.md`
